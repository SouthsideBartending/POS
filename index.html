Drinks for this event

Tick what the client chose — only those show on the Serve screen. Anything you've already poured stays visible even if unticked. Selection is remembered for next time; off-menu extras are always available under “Other”.

Glasses for this event

Tick the glasses you brought — only those show on the breakage screen. Set each fee here; some start blank until you add them. Selection and fees are remembered for next time.

Adjust counts

Correct any drink or glass count by hand. Only items with a count show up here.

Reference prices

These are the à-la-carte prices used only to estimate what the drinks would be worth if sold individually — the basis for the value check at close-out. They are starting estimates: adjust them to your real menu so the comparison means something. They don't affect what the client pays.

Sales

Every paid order, newest first. Tap one to change its payment method or to void it (refund / mistake). Voided sales stay listed for the record but are taken out of the totals and the drink counts.

Staff hours

Add each person working, then tap Clock in when they start and Clock out when they finish. Times can be corrected by tapping them. Hours feed the close-out and the Excel “Staff hours” sheet. Costs use the hourly rate set per role in Settings (internal only — never on the invoice).

Stock count

Count bottles/cans at the start (Open), anything brought in during service (+In) and what is left at the end (Close). Half bottles are fine (0,5). The app works out how many serves that stock should have produced and compares it with what was registered. Serves per bottle are set per drink (tap the number to change it).

Settings

Everything here is saved on this device and kept from event to event. Changes apply immediately. To copy the same setup to another tablet, use Save settings file here and Load settings file on the other device.

Past events

Every event is kept here automatically when you start a new one. Re-export its Excel, save its backup, or compare events side by side. Stored on this device only — export what you want to keep long term.

Export

Builds an Excel workbook on this device — Summary, Consumption, Breakages, Consumption by hour, Billed cocktails, Spirit Serves, Staff hours and Stock tabs, all with live formulas — and opens the share menu so you can save it to Files/Drive, send it by email or WhatsApp. Works offline.

Backup & merge

A backup is a single file holding this whole event. Save one to keep the event safe or move it to another device. Merge adds another device's backup into this one — so two bartenders can each count on their own device, then combine the totals here before exporting.

Start a new event

Clears every count and the setup, ready for the next event. The finished event is first copied to Past events on this device, but still save a backup or export to Excel — clearing the browser data would lose it.
